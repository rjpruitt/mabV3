# Product Component Categorization Flow

## Wall Components

### Selection Flow
1. Individual Component
2. Walls Category
3. Component Type:
   - Wall Panel
   - Wall Set
   - Wall Accent

### Wall Set Configuration
1. **Set Contents**
   - Required: Select included walls
     * Back Wall
     * Left End Wall
     * Right End Wall
   - Optional: Include Accent Panel
     * Yes/No selection
     * If Yes, specify accent placement

2. **Standard Wall Attributes** (Apply to all wall types)
   - Material Options:
     * Acrylic
     * Fiberglass
     * Composite
     * Solid Surface
     * Tile-Look
   
   - Pattern Options:
     * Subway Tile
     * Vertical Subway
     * Chevron
     * Large Format Tile
     * Stone Look
     * Solid Surface

   - Texture Options:
     * Smooth
     * Light Texture
     * Heavy Texture
     * Matte
     * Glossy

   - Panel Configuration:
     * One-Piece
     * Three-Piece
     * Multi-Panel
     * Sectional
     * Trim Options:
       - Corner Pieces
       - Top Cap
       - Bottom Track
       - Seam Covers
     * Seam Locations:
       - Corners Only
       - Mid-Wall
       - Custom

### Wall Accent Details
- Purpose: Decorative band between wall sections
- Standard Width: 6-8 inches
- Installation: Horizontal placement between panels
- Design: Can match or contrast with main panels
- Common in:
  * Tile-look designs
  * Stone-look patterns
  * Decorative patterns
