# Walk-In Shower Kit Structure

## Core Concepts

### Kit Definition
A kit is a pre-selected group of components designed for a specific shower configuration:
- Must match a defined location and shape
- Contains some or all required components
- Each included component has full attribute definitions
- Clearly identifies which components are still needed

### Location & Shape Requirements
1. **Alcove Location**
   - Square Shape
   - Rectangular Shape

2. **Corner Location**
   - Square Shape
   - Rectangular Shape
   - Round Front Shape
   - Neo-Angle Shape

### Size Considerations
1. **Standard Sizes by Location & Shape**
   - Alcove Rectangular: 48x34, 60x32, 60x34, 60x36
   - Alcove Square: 36x36, 42x42
   - Corner Square: 36x36, 42x42, 48x48
   - Corner Neo-Angle: 36x36, 38x38, 42x42
   - Corner Round: 36x36, 38x38, 42x42

2. **Size Impact on Components**
   - Base dimensions determine wall panel requirements
   - Door/enclosure size must match opening
   - Affects placement of:
     * Plumbing fixtures
     * Grab bars
     * Shelving/storage
     * Seating options

3. **Installation Considerations**
   - Minimum space requirements
   - Plumbing location constraints
   - Door swing clearance
   - Accessibility requirements

## Kit Scenarios

### Complete Kit Example
```
Delta Complete Neo-Angle Kit
Location: Corner
Shape: Neo-Angle
Includes:
- Base
  * Material: Acrylic
  * Color: White
  * Drain: Center
- Walls
  * Material: Acrylic
  * Color: White
  * Height: 72"
- Door
  * Glass: Clear
  * Hardware: Chrome
- Fixtures
  * Finish: Chrome
  * Style: Modern
Missing/Required:
- None (Complete Kit)
```

Sterling Base & Walls Kit

Includes:

  * Color: Biscuit
  * Height: 72"
Missing/Required:

## Component Types

### Required Components
1. **Shower Base**
   - Material
   - Color
   - Drain Location
   - Dimensions
   - Threshold Type

2. **Wall System**
   - Material
   - Color
   - Height
   - Panel Configuration

3. **Enclosure**
   - Type (Door/Curtain)
   - Glass Type (if door)
   - Hardware Finish
   - Configuration

4. **Plumbing Fixtures**
   - Valve Type
   - Shower Head Type
   - Finish
   - Features

### Optional Components
- Grab Bars
- Shelving
- Seats
- Niches

## Compatibility Considerations

### Within Kits
- Components must match in:
  * Dimensions
  * Color/Finish Options
  * Installation Requirements

### With Additional Components
- Missing components must be compatible with:
  * Kit dimensions
  * Installation type
  * Finish options
  * Mounting requirements

## Price Structure
- Kit price may differ from sum of components
- Volume pricing considerations
- Installation considerations
- Package deals

## Component Attribute Definitions

### Shower Base Attributes
1. **Material Options**
   - Acrylic
   - Fiberglass
   - Composite
   - Solid Surface
   - Stone

2. **Threshold Type**
   - Barrier Free
   - Low Profile
   - Standard Curb
   - ADA Compliant

3. **Curb Details**
   - Edge Profile:
     * Rounded
     * Beveled
     * Square
     * Decorative
   - Height Options:
     * Zero Entry
     * 2"
     * 4"
     * 6"

4. **Drain Options**
   - Location:
     * Center
     * Left
     * Right
     * End
   - Type:
     * Square
     * Round
     * Linear
   - Finish Options:
     * Chrome
     * Brushed Nickel
     * Oil Rubbed Bronze
     * Matte Black

5. **Anti-Slip Features**
   - Surface Treatment:
     * Textured
     * Pattern
     * Coating
   - Ratings/Certifications:
     * ADA Compliance
     * ASTM Ratings
     * Slip Resistance Value (SRV)

6. **Colors by Material**
   - Acrylic:
     * White
     * Biscuit
     * Bone
   - Solid Surface:
     * [Extended color options]
   - Stone:
     * [Natural color options]

2. **Pattern Options**
   - Subway Tile
   - Vertical Subway
   - Chevron

   - Solid Surface

3. **Texture Options**

   - Light Texture
   - Heavy Texture

4. **Panel Configuration**

2. **Glass Specifications**

### Metallic Finishes
1. **Chrome & Nickel Finishes**
   - Chrome (Bright chrome)
   - Brushed/Satin Nickel
   - Polished Nickel
   - Stainless Steel
   - Brushed Stainless

2. **Bronze Finishes**
   - Oil-Rubbed Bronze
   - Brushed Bronze
   - Venetian Bronze
   - Champagne Bronze

3. **Black Finishes**
   - Matte Black

4. **Gold & Brass Finishes**
   - Gold
   - Brushed Gold
   - Polished Brass
   - Brushed/Satin Brass

4. **Important Notes**
   - Some manufacturers have proprietary finish names
   - Finish matching between manufacturers can be challenging
   - Some finishes are more durable/resistant to water spots
   - Brushed finishes generally show fewer water spots
