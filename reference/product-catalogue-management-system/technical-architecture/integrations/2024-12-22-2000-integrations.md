# Product Catalogue System Integrations

## Current Integrations

### Unwrangle API
- **Purpose**: Product data retrieval from major suppliers
- **Current Suppliers**:
  - Home Depot
  - Lowes
- **Integration Points**:
  - Product search
  - Detailed product information
  - Stock and pricing data
  - Image retrieval

### Implementation Details
```typescript
// Core service configuration
const unwrangleService = {
  baseUrl: process.env.UNWRANGLE_API_URL,
  apiKey: process.env.UNWRANGLE_API_KEY
}

// Search endpoints
- searchHomeDepot({ search, page })
- searchLowes({ search, page, store_no, zipcode })

// Detail endpoints
- getHomeDepotProductDetails({ url })
- getLowesProductDetails({ url, store_no, zipcode })
```

## Integration Patterns

### Data Retrieval
1. **Search Flow**:
   - User initiates product search
   - API call to Unwrangle
   - Results normalized and displayed
   - Error handling for failed requests

2. **Detail Flow**:
   - Product selected from search
   - Detailed data retrieved
   - Data preserved in sourceData
   - Images processed and stored

### Error Handling
- Retry logic for failed requests
- Fallback image handling
- Network error recovery
- Rate limit management
